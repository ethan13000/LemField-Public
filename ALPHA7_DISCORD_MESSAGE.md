**LemField - Alpha 7 Test**

**New / improved**
- Card Explorer: expanded searches and triggers (including +1/+1 counters), a persistent toolbar button, and clearer in-deck states.
- Better printing/token handling: separate token variants, exact-edition hover previews, editable token quantities and faster previews.
- Direct PDF downloads plus print-settings sync and JSON backup/transfer.
- Card counts on Your Decks, alongside reliability and safety fixes.

**Major features**
- Deck guidelines with strategy profiles, live targets, matching-card explanations and requirement searches.
- Card Explorer with EDHREC recommendations and Scryfall discovery; role, type, subtype, trigger, keyword, mana and price filters.
- Add directly to your decks, preview the current deck and hide cards already included. Newly added cards stay visible and muted until reopening Explorer.
- Searchable printing selector with artwork groups, tags and exact-edition previews. Open it with Ctrl+Shift+click or a card's Printings action.
- Proxy printing with custom art, tokens, Letter/A4 sheets, cut guides, rounded corners and PDF export.
- Saved print-edition choices, token quantities, reset/undo and manual settings transfer. Uploaded art stays local.
- EDHREC information on card pages, add-from-Scryfall, feature toggles and optional orange highlighting.

**Install**
Firefox: extract the Firefox ZIP, open `about:debugging#/runtime/this-firefox`, choose **Load Temporary Add-on**, then select `manifest.json`.
Chrome/Edge/Brave/Opera: extract the Chromium ZIP, enable **Developer mode** on Extensions, then **Load unpacked**.
Refresh Moxfield after loading. Firefox temporary add-ons need reloading after a browser restart.

Still alpha: native token edition updates and browser-account sync need live testing. If a token update is rejected, print-only artwork remains available. Safari is unsupported.
